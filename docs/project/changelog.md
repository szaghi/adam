# Changelog

ADAM develops on the `develop` branch. The release notes and the history are on GitHub:

- [GitHub releases](https://github.com/szaghi/adam/releases): one entry per tag, with the tarball and the release notes
  extracted from `CHANGELOG.md`.
- [Commit history](https://github.com/szaghi/adam/commits/develop): every change since the last release.
