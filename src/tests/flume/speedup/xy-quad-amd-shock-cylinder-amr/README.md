# xy-quad-amd-shock-cylinder-amr

Part of the FLUME speedup matrix ([../README.md](../README.md)). Generated by `make_inputs.py` from
`matrix.conf`: edit those, not this file.

## Case

A Mach 2 planar shock over a cylinder of radius 0.13 (axis z) through the domain centre: immersed boundary, Euler wall; the flow of the V6
verification (`verification/shock-cylinder`). The shock starts at x = 0.2 and travels along +x:
post-shock (ρ, u_x, p) = (3.7333, 1.25, 4.5) upstream and at the inflow, pre-shock (1.4, 0, 1), sound
speed 1. Inflow at x-min, outflow (extrapolation) at x-max, inviscid walls on the y faces.
Compressible Euler, ideal gas γ = 1.4, WENO-5 characteristic flux splitting, SSP-33, CFL 0.5,
reflux on.

| Item | Value |
|---|---|
| Geometry | 2-D in the xy plane, z null; quadtree (`ratio = 4`), one cell along the null axis |
| Cells per block | 128 per active axis |
| AMR | dynamic: base level 2, finest 7; one gradient-of-density marker (mode 2, `field = 1`, `var = 1`), `tol = 0.1·Δρ/h(base)`; a regrid every 10 steps, `iters = max - base`, conservative prolongation |
| Grid | base level: 16 blocks, 262144 cells (h = 0.001953125); a uniform grid at the finest level would be 16384 blocks, 268435456 cells (h = 6.103515625e-05) |
| Legs | fnl-amd only (sized for the 192 GB AMD GPUs; run.sh skips it on the other legs unless named) |
| Warmup | to t = 0.15 (incident shock at mid-body), then a restart |
| Window | 100 steps after 10, 3 repetitions, all output off |
| Full simulation | no (speedup data only) |

## Layout

```
xy-quad-amd-shock-cylinder-amr/
  input.ini                      the full-simulation input (run.sh rewrites IO and time per run)
  README.md                      this file
  data/<leg>-np<N>/              the measurement (run.sh <leg> --what data)
    warmup/                      warmup to T_WARM; restart files at its end
    rep<r>-short/ rep<r>-long/   restarted runs of N1 and N1 + NWIN steps, all output off
    timings.csv run.info         wall times; host, executable, launcher, restart step
    result.md                    the cost of this leg (analyze.sh)
```
